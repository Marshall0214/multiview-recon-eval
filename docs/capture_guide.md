# 真实家具采集规范（M4）

## 准备

1. 用 A4 纸打印 [`aruco_board.pdf`](aruco_board.pdf)，打印选项选 **"实际大小 / 100%"**，不要勾选"适合页面"。
2. 用卷尺量**整块图案**，不要量单个方块（卷尺读数误差约 ±1 mm，量 50 mm 的单个方块会带来 2% 的尺度误差，量整块只有约 0.4%）：
   - **总宽**：最左一列方块的左外边缘 → 最右一列方块的右外边缘，理论值 170 mm；
   - **总高**：最上一行方块的上外边缘 → 最下一行方块的下外边缘，理论值 230 mm。
   打印机常有 1–3% 的缩放，所以一定要实测。
3. 选一件家具：纹理丰富、不反光（比如木椅、木桌）。避开纯白、玻璃、金属、镜面。
4. 用卷尺量家具尺寸（mm），口径和程序自动测量保持一致：
   - `height`：地面到最高点；
   - `width`：左右方向最宽处（通常是扶手外沿）；
   - `depth`：**座面**前后方向的深度（卷尺在座面上前后拉直即可）；
   - 另外可记录 `overall_depth`：俯视时最前端到最后端的水平距离（含后倾靠背的外伸，卷尺不好量，可选）。
   自动测量只输出整体高 / 宽 / 占地进深；座面等分层尺寸用 `scripts/real/bands.py` 手动对比（见 results/m4_real_chair.md）。

## 摆放

- 标定板**平铺在家具旁边的地面上**。不要弯折，不要被家具挡住，离家具 10–30 cm。
- 标定板能同时提供米制尺度、地面平面和坐标朝向。

## 拍摄（iPhone 12）

- 用 **1x 主摄**，拍摄过程中不要切换 0.5x 或 2x，不用人像模式。
- 对着家具**长按屏幕，锁定对焦和曝光（AE/AF 锁定）**，整个拍摄过程保持锁定。
- 拍两圈：
  - 第 1 圈：手机举到腰部高度，斜向下约 30° 拍，40–60 张；
  - 第 2 圈：手机放到膝盖高度，稍微向下拍，40–60 张。
- 相邻两张的画面重叠要超过 70%，也就是每走一小步拍一张，不要走一大步才拍。
- 保证至少 20 张照片里能完整看到标定板。
- 光照均匀，不要有阳光直射。拍摄者的影子不要落在家具上。画面里不要出现人脸或证件。
- 总数 80–120 张。

## 上传

```
data/real/<名字>/images/          # 原图，data/ 已加入 .gitignore，不会入库
data/real/<名字>/measurements.json
```

`measurements.json` 示例（如果有卡尺量过单个方块，也可以不填这两项，改填 `"marker_mm": 49.6`）：

```json
{
  "board_width_mm": 169,
  "board_height_mm": 229,
  "object": "wooden chair",
  "dims_mm": {"height": 812, "seat_height": 452, "width": 455, "depth": 520}
}
```
