# 真实家具采集规范（M4）

## 准备

1. 用 A4 纸打印 [`aruco_board.pdf`](aruco_board.pdf)，打印选项选 **"实际大小 / 100%"**，不要勾选"适合页面"。
2. 用直尺量出**任意一个黑色方块的外边长**（mm，精确到 0.5 mm）。理论值是 50 mm，但打印机常有 1–3% 的缩放。
3. 选一件家具：纹理丰富、不反光（比如木椅、木桌）。避开纯白、玻璃、金属、镜面。
4. 用卷尺量 3–5 个尺寸（mm），比如总高、座面或桌面高度、宽度、进深。

## 摆放

- 标定板**平铺在家具旁边的地面上**。不要弯折，不要被家具挡住，离家具 10–30 cm。
- 标定板能同时提供米制尺度、地面平面和坐标朝向。

## 拍摄（iPhone 12）

- 用 **1x 主摄**，拍摄过程中不要切换 0.5x 或 2x，不用人像模式。
- 对着家具**长按屏幕，锁定对焦和曝光（AE/AF 锁定）**，整个拍摄过程保持锁定。
- 拍两圈：
  - 第 1 圈：手机举到腰部高度，斜向下约 30° 拍，40–60 张；
  - 第 2 圈：手机放到膝盖高度，稍微向下拍，40–60 张。
- 相邻两张的画面重叠要超过 70%，也就是每走一小步拍一张，不要走一大步才拍。
- 保证至少 20 张照片里能完整看到标定板。
- 光照均匀，不要有阳光直射。拍摄者的影子不要落在家具上。画面里不要出现人脸或证件。
- 总数 80–120 张。

## 上传

```
data/real/<名字>/images/          # 原图，data/ 已加入 .gitignore，不会入库
data/real/<名字>/measurements.json
```

`measurements.json` 示例：

```json
{
  "marker_mm": 49.6,
  "object": "wooden chair",
  "dims_mm": {"height": 812, "seat_height": 452, "width": 455, "depth": 520}
}
```
