# multiview-recon-eval

**面向家具数字孪生的 3DGS 重建质量评估与补扫视角选择**

在机器人或机械臂扫描家具时，首轮采集往往存在盲区（够不到的角度、被遮挡的一侧）。本项目研究：**能否在没有真值的情况下，仅凭重建结果本身判断"哪里重建得差"，并据此选择补扫视角，使几何完整性提升得比随机或均匀补拍更快。**

## 3. 方法：无真值质量信号

对每个候选视角 v，用当前 3DGS 模型渲染，计算：

| 信号 | 定义 | 直觉 |
|---|---|---|
| **S1 不透明度空洞** | 物体区域内累积不透明度 α < τ_α 的像素比例 | 没重建出来的区域 |
| **S2 观测支持度** | 对每个高斯记录其在训练视角中可见（混合权重 > ε）的次数 c；视角得分为像素主导高斯的 1/(1+c) 加权平均 | 被看得少的区域不可靠 |

- 组合得分：S1、S2 在候选池内分别做 z-score 后**等权相加**。权重事先固定，不在测试集上调参。
- **批量选择**：按得分贪心取 top-N，并做角度非极大值抑制（与已选视角夹角 < θ 的候选跳过），避免一次选中 5 个相邻视角。

**基线**：
- 随机：从候选池中均匀随机抽取
- 最远点采样（FPS）：在相机方向空间中选离已有视角最远的候选

更重的方法（如基于 Fisher 信息的 FisherRF）作为相关工作讨论，列入未来工作。

### 4.2 视角设置

| 项目 | 设置 |
|---|---|
| 候选视角池 | 物体周围球面均匀采样，数量拟定 200（M2 前冻结） |
| 测试视角 | 独立于候选池的另一组球面采样，数量拟定 60 |
| 初始视角 I-均匀 | 球面均匀采样 K=10 |
| 初始视角 I-偏置 | 仅上半球、单侧采样 K=10（模拟机械臂够不到的区域 / 遮挡侧） |
| 每轮补扫 | N=5 张，共 R=4 轮（最终 30 张） |
| 训练 | 每轮从头训练，超参数使用 gsplat 默认值，改动逐项列在 `configs/` |

### 4.3 补扫实验规模

3 件家具 × 2 种初始配置 × 3 种策略 × 4 轮 × 2 个随机种子 = **144 次训练**。单次训练耗时在 M0 实测后填入：__ 分钟。

### 4.4 指标

| 层级 | 指标 | 计算方式 |
|---|---|---|
| **主指标** | F-score@τ，同时报告 Precision / Recall | gsplat 渲染深度 → Open3D TSDF 融合 → 网格，与真值网格比较；τ = 包围盒对角线的 1%，另报 0.5% / 2% 检查敏感性 |
| 副指标 | PSNR / SSIM / LPIPS | 固定测试视角 |
| 代价 | 单次选视角耗时 | 同一 GPU 上计时 |
| 信号有效性（Q1） | Spearman ρ | 每轮对全部候选视角计算"信号得分"与"真实误差"（渲染深度与真值深度的误差、LPIPS），按物体和轮次分别计算后取平均 |

Recall 用来衡量**完整性**，是补扫策略最应该提升的指标。

### 4.5 评测管线自检

- **几何管线**：把 Blender **真值深度**做 TSDF 融合，与真值网格计算 F-score，结果应接近 1。否则说明融合或对齐有 bug。
- **渲染管线**：Mip-NeRF 360 上的 PSNR 与 gsplat 公开结果对照。

### 4.6 真实数据验证

1. 打印 ArUco 标定板，用卷尺实测标记边长（打印机可能有缩放）。
2. 手机环绕拍摄家具（锁定对焦与曝光），画面中包含标定板。
3. COLMAP 估计位姿 → 由 ArUco 角点三角化恢复米制尺度 → gsplat 训练 → 网格。
4. 在网格上量取 3–5 个关键尺寸（长 / 宽 / 高等），与卷尺实测值对比。

## 7. 局限与未来工作

- 主实验基于合成渲染，与真实数据之间存在域差距（光照、噪声、位姿误差），真实数据部分只做单个物体的验证。
- 规模有限（3 件家具），结论不做一般性推广。
- 未来工作：
  - 与 FisherRF 等方法对比
  - 增量训练与从头训练的对比
  - 用 ARKit VIO 位姿替代 COLMAP，评估机器人自身位姿能否直接用于重建
  - 使用 ScanNet++ 等真实室内数据集，引入房间级遮挡
